# Локальный запуск WordPress

Проект подготовлен для запуска через Docker Desktop. Исходный статический сайт находится в соседней папке `site2` и не изменяется.

## Первый запуск

1. Установите и запустите Docker Desktop.
2. Откройте PowerShell в этой папке.
3. Выполните `./local-start.cmd`.
4. Откройте `http://localhost:8080`.

При первом запуске скрипт создаёт базу данных, устанавливает WordPress на русском языке, активирует тему `custom-site-theme`, создаёт главную страницу, страницу мастер-класса и два меню.

## Остановка

Выполните `./local-stop.cmd`. База данных сохраняется в постоянном Docker volume и не удаляется обычной остановкой.

## Редактирование

- Название и логотип: **Внешний вид → Настроить → Свойства сайта**.
- Меню: **Внешний вид → Меню**.
- Тексты и портреты главной страницы: **Внешний вид → Настроить → Содержимое сайта**.
- Описание мастер-класса: **Страницы → Мастер-класс №1**.
- Заголовок мастер-класса: редактируется как название страницы.

## Перенос на хостинг

Для публикации нужны файлы WordPress, включая `wp-content/themes/custom-site-theme`, а также экспорт локальной базы данных и загруженные через админ-панель файлы из `wp-content/uploads`. Секреты из `.env` на хостинг не копируются — на сервере используются отдельные доступы к базе данных.
