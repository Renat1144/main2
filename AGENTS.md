# Правила проекта

- Исходный HTML-сайт в соседней папке `site2` является визуальным эталоном.
- Дизайн, тексты, изображения, размеры и расположение элементов нельзя менять без явного указания пользователя.
- Оригинальную папку `site2` нельзя изменять: она используется только как источник и эталон для сравнения.
- Системные файлы WordPress в `wp-admin` и `wp-includes` нельзя редактировать.
- Вся пользовательская разработка выполняется в `wp-content`, преимущественно в теме `wp-content/themes/custom-site-theme`.
- Перед завершением нужно проверять ширины 1440, 1024, 768 и 390 px, консоль браузера, PHP-ошибки и отсутствие битых ресурсов.
- Новые зависимости добавляются только при реальной необходимости.
- Все пути, ссылки и ресурсы должны продолжать работать после переноса сайта на другой домен.
- Секреты хранятся только в локальном `.env`; файл `.env` нельзя публиковать в репозитории.
- Коммит и отправка в GitHub выполняются только по отдельной просьбе пользователя.
- При каждом обновлении GitHub публикуется актуальная WordPress-версия сайта без `.env`, `wp-config.php`, базы данных, резервных копий, пользовательских загрузок, журналов, служебных скриншотов и других персональных данных.
- Перед каждым коммитом в GitHub нужно проверить правила `.gitignore`, состав подготовленных файлов и выполнить поиск паролей, ключей и токенов.
